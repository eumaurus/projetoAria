Separação de responsabilidades
Agentes (ConsultaAgent) só orquestram lógica de negócio — nunca chamam Vertex AI ou DuckDB diretamente.
Serviços encapsulam infraestrutura: GeminiService, SqlExecutor, DataService, etc.
Injeção de dependência centralizada em app/container.py via construir_container().
Estado (TypedDict) é a fonte de verdade única da State Machine.
Como executar
Configurar ambiente:

copy .env.example .env
Preencha GOOGLE_CLOUD_PROJECT e autentique no GCP (gcloud auth application-default login).

Instalar dependências (máquina atual: Python 3.12.6 via py; 3.13 não está instalado):

py -m pip install -r requirements.txt
Dados de exemplo (já gerados; regerar se quiser):

py scripts/gerar_dados_exemplo.py
CLI:

py main.py -p "Qual o total de vendas?" -e admin@lux.com
Streamlit:

py -m streamlit run streamlit_app.py
Validação local

Usa mock se GOOGLE_CLOUD_PROJECT estiver vazio; caso contrário, vertex
Factory em criar_gemini_service() escolhe automaticamente a implementação. O GeminiMockService simula:

SQL heurístico (totais, agrupamentos, top clientes)
Respostas RAG a partir do contexto recuperado

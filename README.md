# projetoAria
O A.R.I.A. é uma plataforma de AIOps preditivo que analisa o histórico operacional da Locaweb para antecipar incidentes e riscos de quebra de OLA, apoiando o gestor a agir antes que o problema aconteça — com previsão de volume, um índice de saúde operacional e um copilot conversacional que responde perguntas sobre incidentes e KPIs em tempo real.
